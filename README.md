# FATE Project

FATE Project is an independent software project focused on practical Android applications, small web tools and Telegram bots.

## Current products

### Android
- [Cost & Profit](https://www.rustore.ru/catalog/app/com.fateproject.costandprofit) — cost, profit, margin and markup calculations.
- [Genesis Business](https://www.rustore.ru/catalog/app/com.fateproject.genesis) — structured support for complex business decisions.

### Telegram
- Психология дизайна (Design Psychology) — a completed Telegram bot.
- [Монетка судьбы | Fate Coin](https://t.me/monetka_sudby_bot)
- [Столицы мира | World Capitals](https://t.me/capitals_world_game_bot)
- [Калькулятор маржинальности | Margin Bot](https://t.me/margin_business_bot)

### Web tools
- [Калькулятор маржи](https://fateproject.ru/kalkulyator-marzhi.html)
- [Столицы мира](https://fateproject.ru/stolitsy-mira-test.html)
- [Подбросить монетку](https://fateproject.ru/podbrosit-monetku.html)

## Project status

In 2026 FATE Project discontinued a previously explored experimental digital-asset direction after changes in the Russian regulatory environment, including Federal Law No. 282-FZ of 4 August 2026 "On Digital Currencies and Digital Rights", effective from 1 September 2026.

That direction is closed and is no longer developed or promoted by FATE Project. The project's current activity is software products and digital tools.

Historical repository history is retained as part of the development record and is not presented as the current product direction.
