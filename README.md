# FATE Project


FATE Project is a founder-led digital project developing practical software tools and digital legacy concepts. FATE is the project’s fixed-supply BEP-20 token on BNB Smart Chain. Its first public token-related function is a read-only holder verification beta. No presale or project fundraising round has been conducted. A FATE/WBNB pool exists on PancakeSwap V3. Its existence does not establish independent demand.

## Current token function

The first public token-related function is the [FATE Holder Verification beta](https://fateproject.ru/holder-verification.html). It reads the connected wallet’s FATE balance using a read-only blockchain call in the user’s browser.

It does not transfer tokens, request token approval, request message signatures, access private keys, award tokens, promise rewards, or provide financial returns. Wallet addresses and balances are not stored by FATE Project.
