Public project and token information

Practical software, documented openly.

FATE Project is a founder-led digital project developing practical software tools and digital legacy concepts. FATE is the project’s fixed-supply BEP-20 token on BNB Smart Chain. Its first public token-related function is a read-only holder verification beta. No token sale, liquidity pool, exchange listing or active trading currently exists.

Current token function

Read-only holder verification beta

What it does

The tool reads the connected wallet’s FATE balance through a read-only blockchain call made in the user’s browser.

Open the holder verification beta

What it does not do

  • It does not transfer tokens or request token approval.
  • It does not request a message signature.
  • It does not access private keys or seed phrases.
  • It does not provide rewards or financial returns.
