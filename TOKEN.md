## Current token function

FATE’s first public token-related function is a read-only [holder verification beta](https://fateproject.ru/holder-verification.html). It reads a connected wallet’s FATE balance through `eth_call` in the user’s browser.

The beta does not transfer tokens, request token approval, request a message signature, access private keys or seed phrases, award tokens, promise rewards, or store wallet addresses and balances.
