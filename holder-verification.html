How it works

1. User-controlled connection

A wallet connection request begins only after the user selects “Connect browser wallet.”

2. Network check

The tool requires BNB Smart Chain mainnet, chain ID 0x38, and offers a visible switch request when another network is active.

3. Read-only balance call

The browser makes an eth_call to balanceOf(address) and displays the returned FATE balance.

Privacy and security notice

This beta performs a read-only blockchain balance check in the user’s browser. It does not request token approval, token transfers, message signatures, private keys or seed phrases. Wallet addresses and balances are not stored by FATE Project.

No analytics, trackers, server submission, gated paid access, token award or reward mechanism is used.

Limitations

  • A positive balance verifies only that the connected address currently holds FATE.
  • The check does not establish identity, ownership of another address, eligibility, value or financial status.
  • Wallet availability and RPC responses are controlled by the user’s wallet provider.
  • No reward, return or future benefit is promised.
